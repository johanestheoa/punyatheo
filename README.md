# Johanes Theo Adrian — Portfolio

Vanilla HTML + CSS + JavaScript portfolio.

## Run

Open `index.html` with VS Code Live Server.

## Customize

- Personal/education content: `index.html`
- Roles: `js/main.js`
- Certificates: `js/certificates.js`
- Projects: `js/projects.js`
- GitHub username: `js/github.js`
- Social/contact links: `index.html`
- Supabase: `js/supabase.js`

## Assets

Replace the placeholder files in:
- `assets/profile/`
- `assets/certificates/`
- `assets/projects/`

The HTML already contains graceful placeholders if images are missing.

## GitHub

Public repositories are loaded from GitHub's public REST endpoint for the configured username.

## Supabase

See comments in `js/supabase.js` for the table and RLS setup.
